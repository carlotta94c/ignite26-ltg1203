# Foundry sample development

This project was built with the microsoft-foundry skill. Before working on or answering
questions about foundry agents, read the microsoft-foundry skill first.
If you are in VS Code, read the vscode-microsoft-foundry skill first.

Keep the prompt and hosted solutions independent. Preserve the Caldova CSV and commercial-analysis
instructions in both solutions. The hosted solution is in csv-chart-analysis-hosted and reuses
the existing gpt-5.4-nano deployment.
Provisioning, deployment, and role changes require an explicit user request.
